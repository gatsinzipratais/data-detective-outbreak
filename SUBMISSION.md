## Description

Data Detective: Outbreak is a live cross-device cooperative mystery game. Players take specialist roles, share private evidence, choose limited investigation moves, and make one containment call together. Building real-time room sync was the challenge; the asymmetric roles made testing fun. I learned how to turn a static web game into a shared experience. Next, I would add more cases and accessibility options.
